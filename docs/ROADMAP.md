# 首版开发路线图

技术路线：Vite + React + TypeScript + Three.js + 本地 Node API。完整方向是通过表达与国内 AI 交流形成情绪雕塑，照片先在本地粒子化，再接入内容理解与存档。2026-10-20 用户确认先补粗版功能，视觉与提示词精修后置；百炼北京为选型起点。基础 T01 的球壳造型与早期界面未获用户认可，当前暗房首屏和星云引擎保留；不将工程检查等同于产品验收。

一次只推进一个可运行、可验收的小任务。T01-A 暂告一段落；B1 网格观感未获认可，用户认为 B2 初步接近目标，现提供 B3 局部拨动试样，待用户确认手感。

## T01-A：暗房首屏与有机星云重构

目标：用有厚度、褶皱和冷暖光晕的可互动星云替代原球壳，完成用户指定的暗房入口。

- [x] 满屏指定径向渐变与透明画布；品牌、THE DARKROOM / GALLERY / INFO 导航和三行衬线标题。
- [x] 22,000 点核心聚集、褶皱涡流与边缘消散；暖白琥珀 → 冰蓝银灰 → 紫蓝，逐点颜色/大小/透明度与柔软叠加发光。
- [x] 缓慢环境流动、指针与触屏事件排斥和涡流、弹簧阻尼归位；移除 OrbitControls 的旋转与缩放。
- [x] 底部毛玻璃胶囊与倾听/书写/投射三个入口；未开放输入和 GALLERY 只显示准确提示。
- [x] INFO 可打开并用 Esc 关闭，THE DARKROOM 清除提示并聚焦画布；环境减少动态效果与页面隐藏处理已实现。
- [x] 类型检查与生产构建通过；本机 Chrome 1468 × 970、390 × 844、320 × 640 与 844 × 390 检查，画布数量为 1，无页面溢出，检查期间控制台无新增警告或错误。
- [x] 实际动画函数在内存运行 600 帧，22,000 点均为有限数值；模拟扰动后的回弹可稳定归位。此项不是实际设备性能测试。
- [ ] 真实触屏设备、长期性能与 GPU 内存验证；上述窄屏与横屏仅为桌面 Chrome 视口模拟。
- [ ] 用户认可界面与雕塑观感（待本人确认）。
- [ ] 开发者能解释 React 状态、CSS 布局、粒子采样、ShaderMaterial 与弹性回归的数据流（待本人确认）。

## T01-B：照片粒子浮雕（分步推进）

### B1：照片平面点云（工程实现，待用户验收）

- [x] 本地 JPG / PNG / WebP 读取、降采样、平面位置/原色/源透明度；原比例和方向保留。
- [x] 更换图片、同文件重选支持、读取失败保留原画面、THE DARKROOM 返回；资源清理。
- [x] 类型检查、生产构建、像素映射断言与本机浏览器横竖图验证。
- [ ] 本人选择非私人图片验收颜色与比例，解释“像素 → 数组 → 点云”。

### B2：照片浮雕厚度（视觉试样待验收）

- [x] 实现亮度影响点大小/透明度、艺术化厚度、轻微弯曲、边缘消散与低频流动；具体观感待验收。
- [ ] 保留原图主体、颜色和粒子清晰度；不宣称真实三维重建。

### B3：照片局部互动（试样已接入，手感待验收）

- [x] 接入鼠标划过/拖动的局部拨开、松开或移开后渐进回位，真实函数数值检查与浏览器拖动/恢复检查通过。
- [ ] 用户认可力度、范围与回位速度；不同明暗图片验收，测试真实触屏和资源稳定性。

每一步独立验收；照片粒子化不需要大模型或 API。

## T02-A：百炼文字对话（本地工程与真实单轮联调已通过）

目标：完成可连续交流、可停止与重试的文字链路；暂不改变粒子。

- [x] 书写面板、内存上下文、流式显示、停止/重试/清空与未配置提示。
- [x] 本地 Node API 与同源代理；密钥只由后端读取，输入校验、基础限流与超时。
- [x] 类型检查、构建、8 项本地协议测试；浏览器模拟响应验证连续对话、失败重试、停止与返回暗房。
- [x] 配置真实北京密钥与业务空间地址，后端及真实网页均以虚构输入收到完整模型回复；后端单次约 1.7 秒，不是延迟承诺。
- [x] 使用当前照片完成两轮真实追聊和相反的视觉调整。
- [ ] 更多网络条件下的速度与实际费用账单验证。
- [ ] 用户实际确认文字交互可用；真机输入法/软键盘及普通网络验证。

## T02-B：照片理解与视觉参数（工程与两轮真实调用已验证）

目标：让照片和文字通过国内模型生成经过校验的有限视觉参数。

- [x] 选择照片只在本地处理；主动发送时才上传 768 像素内的 JPEG 缩略图，附发送说明，可无文字直接发图。
- [x] 一次 JSON Schema 流式调用同时返回回复及视觉参数，参数经两端有限数值校验/范围限制后平滑应用。
- [x] 网络失败/截断不改画面，参数无效保留回复和已有画面；更换照片取消旧请求并重建当前对话。
- [x] 构建、12 项接口/流式检查、2 项参数检查和 5 项原照片运动回归通过；真实风景图看图/追聊、窄屏及模拟取消/异常路径通过。
- [ ] 本人解释请求、校验与渲染三者职责；用户视觉/回应认可、真实触屏/软键盘、长时间 GPU 与多网络验证。
