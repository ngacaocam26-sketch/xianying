# 演示视频分镜脚本（≤ 3 分钟）

目标时长 2 分 50 秒，留 10 秒余量。所有输入都是虚构的示例句，不出现真实的个人信息、聊天或照片。

## 拍摄前准备

- **用本地版本录**：`npm.cmd run dev`，浏览器打开 `http://127.0.0.1:5173`。不受香港线路晚高峰影响，画面最流畅。
- **画面**：
  - 电脑录屏 1920×1080，浏览器按 F11 全屏，隐藏书签栏。
  - 手机镜头单独用系统录屏，竖屏，后期放进画中画。
- **清空回廊**：先用一个新的浏览器窗口（或无痕窗口）把下面要用的作品存进去，回廊里不要有真实作品。
- **准备一张照片**：风景、天空、街景这类，不要有人脸和个人信息。
- **AI 每次的回复和意象都会有些不同**：每段多录两三遍，挑效果最好的那遍。下面的句子都在真实模型上试过，大多数时候会出对应的意象。
- **配乐**：选一段安静的钢琴或环境音乐（需可商用、无版权问题），音量压低，旁白优先。
- **字幕**：旁白全部配字幕；用户输入和 AI 回复本身就在画面里，不用重复。

## 旁白全文（约 420 字，正常语速约 2 分 20 秒）

> 有些感受，说不清，也放不下。
>
> 显影，把此刻的情绪，变成一件可以触碰的粒子雕塑。
>
> 你说出一句话。AI 读懂的是处境，不只是关键词：它从十二种意象里为这一刻挑一个，起一个名字，再决定冷暖、明暗、松紧。回复不是安慰套话，而是帮你看清——比如，难受的可能不只是生气，还有在所有人面前下不来台。
>
> 同样是难受，委屈可能是一场雨，焦虑是停不下来的漩涡，喜悦是慢慢打开的花。
>
> 你可以触碰它。拨开它的时候，AI 会感觉到，轻轻问你一句。一位试用者说，这像是把一团乱麻划散了，烦恼也跟着散开了。
>
> 倾诉时，它简短地陪着你；你真的想问为什么的时候，它会把话说透，给你能做的下一步。它不是心理咨询，也不会给你贴标签。
>
> 不想打字，可以直接说；也可以投一张照片，让这一刻的画面自己显影。
>
> 想留下的时候，就让它凝结。AI 为这一刻起一个名字，它会以记忆碎片的样子，留在只属于你的回廊里。
>
> 也可以，让它散去。

## 剪辑提示

- 先按分镜分段录，再剪到一起；每段开头结尾各多留 1 秒，方便转场。
- 显影动画约 3 秒，不要剪断「散开—凝聚」的过程，这是作品的核心画面。
- 总长超过 3 分钟时，优先压缩第 4 段（三段快剪可以只留两段）和第 7 段。
- 导出 1080p、30 帧，导出后完整看一遍，确认时长不超过 3:00。
