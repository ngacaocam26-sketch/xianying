# 产品目标与首版范围

## 已知目标

- 项目名：显影：把一次情绪变成可触摸的粒子雕塑。
- 目标用户：习惯用文字、声音、画面表达自己的年轻人。
- 想解决的问题：让难以说清的情绪被看见、被放下。
- 开发者起点：学过一些前端，使用本地 VS Code，尚不能独立完成整个网页。
- 首要目标：真正理解架构和开发；三个实际开发日作为初始时间盒参考，按学习与验收情况调整。

## 完整愿景

表达当下状态 → 输入实时驱动粒子 → AI 把内容转译成形态和质感参数 → 凝结为 3D 粒子雕塑 → 呼吸或指尖互动 → 保存至个人回廊或让作品散去。

“可触摸”首先指屏幕中的指针、触屏互动；目前没有实体输出或触觉硬件实现。

即时反馈和内容理解是两层机制：输入一变化就有可见回应；AI 的内容转译可以稍后完成。作品是否贴合表达，需要用户自己判断。

## 当前粗版交付顺序（2026-10-20）

用户明确先把基本功能补全，再精修前端效果与心理提示词。比赛仅要求国内 AI，没有限定平台；目标是国内普通网络可访问。当前采用阿里云百炼北京地域作为起点，文字先用 `qwen3.8-flash`，照片理解后续可评估复用该视觉型号，实时语音用专门型号。替代此前 Gemini 计划，不把平台选型当作情绪回应质量已获验证。

当前已实现文字/照片连续对话、流式回复、停止/重试/清空、Node 接口和受限视觉参数联动；独立实时语音已接通说/听/打断。凝结、命名、保存、散去、本地回廊打开和可恢复移除已接通：照片作品与真实文字 AI 参数作品都验证刷新后恢复。物理设备及回应是否符合产品期待仍待体验；国内手机网络和上线尚待安排。

顺序：文字真实联调 → 照片理解与受限视觉参数 → 实时语音 → 凝结、保存/散去与本地回廊 → 手机和异常处理 → 上线。视觉与提示词只做可用基线，本轮不继续打磨默认雕塑。

## 已确认的体验方向（2026-10-19，模型选择已更新）

用户明确：核心是把情绪具象化。2026-10-21 确认文字/语音都应自然形成作品、表达时持续看见画面。已接通输入脉动 → 内容转译 → 连续结构变化 → 凝结/保存或散去 → 回廊恢复。暗房与选定雕塑保留为起点，新增形态变化属于核心显化功能；材质、心理对话措辞与用户满意度仍待后续精修/验收。

- 照片提供原始颜色和可辨认的内容；采样后映射为有厚度、轻微弯曲、边缘逐渐散开的粒子浮雕。亮度控制点大小与透明度，暗部保留可见下限；艺术化深度不等于真实三维重建。
- 国内模型提供八项有限作品参数：疏散/流动/冷暖/开放/张力/连贯/轻重/明暗，校验后平滑变化；可表达混合感受，不依靠几个关键词固定套型，不因 AI 安慰就把作品改为开心。等待/失败保留画面，模型诠释是否贴合由用户判断。
- 说、写、拍共用暗房。语音即时音量反馈和稳定转写后的作品转译已接通，与文字共用作品参数/转译指导；对话历史各自独立，不读取页面照片。插话取消旧音频与待完成转译，结束/切换/凝结/隐藏停止并防止过期结果回写，不保存录音。
- 凝结后固定基础形态/当前作品参数和环境相位，仍可互动，临时拨动会归位。主动保存到 IndexedDB，照片保存恢复用降采样数据，默认雕塑保存固定种子/版本；名称/日期/预览随作品保留，原始文字、录音、原图和上传附件不存档。散去不新增或删除存档，回廊移除可恢复。
- AI 请求需要联网。发送前说明：当前文字、最近 5 轮完整对话及当前照片缩略图会发给阿里云百炼。没有文字时可直接发送照片；原图不上传。语音在开始后持续上传，最长 5 分钟。开发验证使用虚构文字、合成语音和非私人示例素材。

## T01-A 保留范围：暗房首屏与包裹形雕塑

当前首屏与粒子渲染保留以下内容；本轮不调整默认雕塑或界面布局：

- 全屏暗房径向渐变背景，透明 WebGL 画布；22,000 颗粒子形成有厚度的连续卷折曲面，构成向内包裹、偏侧开口的雕塑，周围带少量浮尘。
- 冰蓝、银灰与紫蓝勾勒曲面，两处内褶透出暖白琥珀光；约 95% 清晰亮核与 5% 柔光保留颗粒和发光质感，整体缓慢呼吸起伏。
- 指针与手指划过产生局部排斥和涡流，移开后弹性归位。不使用原 OrbitControls 的自由旋转和滚轮缩放。
- 顶部「显影 XIAN YING」与 THE DARKROOM / GALLERY / INFO；居中三行诗意标题；底部统一毛玻璃胶囊内为「倾听 / Speak」「书写 / Type」「投射 / Capture」。
- 移除调试标签、数量统计、暂停、重置与边角说明。必要介绍位于 INFO，尚未开放功能只在点击后准确提示。

基础形体与照片采样由本地程序生成，AI 参数在后端与前端校验后调整整体疏散、流动和冷暖，不解释成心理测量。文字/照片与独立实时语音已接通真实模型；凝结与本地作品保存的基本流程已验证。B3 的照片拨动/回位保留，视觉精修后置。工程检查通过与用户视觉认可分别记录。

采用 Vite + React + TypeScript + Three.js，不使用 Tripo。Node API 随文字接入创建，实时语音使用服务端 ws 依赖；任务见 [ROADMAP](ROADMAP.md)，职责见 [ARCHITECTURE](ARCHITECTURE.md)。

## T01-B2 / B3 当前范围：本地照片粒子浮雕与互动试样

点击投射选择本地 JPG / PNG / WebP，以原色、方向和宽高比为基础生成细颗粒画面；带轻微厚度、弯曲、明暗变化和流散边缘。叠光与边缘淡出会改变照片外观。再次点击可更换，THE DARKROOM 返回默认雕塑。取消或读取失败保留当前画面；选择时不发网络请求，主动发送才上传重新编码的缩略图，不自动保存。

用户认为 B1 网格观感与参考视频不符，B2 后反馈“有点那个感觉”，并授权 B3 试验鼠标拨开与慢恢复。现已接入照片局部拨动、少量旋流及渐进回位；保持界面与 B2 材质，手感待用户验收。原暗房雕塑的互动保留；照片粒子化不需要大模型或 API。

## 四种形态试样（2026-10-21）

2026-10-21 新增独立四形态试样：用户认为当前单一包裹形调参数仍相似，先在 `/shape-studies` 查看交织丝线、垂落体、舒展曲带和分离粒子群。统一银蓝颜色、每件 22,000 点和相同视角，默认静态，可同步转动和逐件放大。试样尚未替换暗房，也未接文字、语音、拨动或存档；区分度与观感等待本人验收，再安排后续接入。

## 暂缓范围

真实呼吸识别、音乐输入、完整三维重建、服务端数据库、用户账户、云端回廊和多设备同步。语音内容驱动作品已接通，对话与照片/文字的统一历史仍未实现；按需创建文件，不提前建立这些模块。

## 如何判断有进展

- 工程验收：页面可运行、交互有反馈、状态可重置、保存行为可复现。
- 学习验收：开发者能解释每个文件的职责和一条数据流；目前尚未由本人验证。
- 产品验证：未来用自愿提供的体验反馈判断作品关联感、互动意愿及结束感；当前未开展。

不把工程测试通过等同于学习效果或产品价值已获验证。
