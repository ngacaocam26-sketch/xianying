# 百炼 API 开通与本地联调

当前用北京地域的 `qwen3.8-flash` 同时处理文字与照片理解，对应控制台的 **Qwen3.8-Flash**。一次请求返回自然回复及受限作品参数；实时语音已使用 `qwen3.8-omni-flash-realtime`，沿用本机北京 API Key 和业务空间，不需另接国外服务。

当前这台电脑已配置，文字、两轮真实看图/粒子联动及合成语音的真实服务链路已验证。以下步骤保留作重新配置参考；更换密钥时直接编辑本机 `.env`，不要将新密钥贴入聊天。

## 开通或重新配置

1. 打开 [阿里云百炼控制台](https://bailian.console.aliyun.com/)，登录并按页面指引开通。地域选择 **华北 2（北京）**；若提示需要认证，按控制台要求完成。
2. 进入 **API Key** 管理，使用默认业务空间创建一个北京地域的普通模型 API Key。不要为此购买 Coding Plan；本项目调用普通模型 API。
3. 在模型列表找到 `qwen3.8-flash`，查看当前账号是否有免费额度、剩余额度及有效期；试用阶段先开启 **免费额度用完即停**。有额度不等于账号和模型一定可以调用，以实际响应为准。
4. 在 VS Code 项目文件树打开根目录 `.env`。本轮已从模板创建空白文件；不要把密钥发到聊天、截图、前端代码或 GitHub。将第一行配置填成 `DASHSCOPE_API_KEY=你的实际密钥`；保留 `QWEN_MODEL=qwen3.8-flash`。
5. `DASHSCOPE_WORKSPACE_ID` 可先留空，代码使用官方北京 DashScope 兼容接入地址。若填写北京业务空间 ID，代码自动使用官方推荐的业务空间专属域名；它与 API Key 需要属于同一地域和业务空间。
6. 保存 `.env`，停止旧启动任务，再在 VS Code 按 `Ctrl+Shift+B` 运行「显影：启动并预览」。也可在项目终端运行 `npm.cmd run dev`。**首次切换本轮启动方式、修改密钥、模型或服务端提示词后都需重启**；只刷新浏览器不会重新读取后端配置。
7. 打开新启动任务显示的 Local 地址，点击 **书写**。先发送虚构测试句，例如「测试情境：明天展示作品，有一点紧张」，看到完整回复后，再测试追问、停止回复和重试。

终端显示“已读取本机配置”只表示配置存在，不表示密钥有效或模型已联通。本地旧预览地址可能还在运行；以新任务显示的地址为准。后端自动选择空闲端口，网页开发端口占用时顺延。

## 配置与费用边界

- `.env` 被 Git 忽略，只有不含密钥的 `.env.example` 可以提交。密钥由 Node 服务读取，浏览器通过同源 `/api/chat` 请求；不使用 `VITE_` 密钥变量。
- 页面不会自动请求模型。每次点发送或重试才调用一次，最长等待 45 秒，最多生成 900 tokens（含回复及参数 JSON）。服务端限制同时 2 个请求、每分钟最多 20 次尝试；这些是开发阶段的保护，不代替平台账户额度设置。
- 发送当前文字及最近 5 轮完整对话；当前单条输入最多 2000 字。未完成的回复不进入后续模型上下文。应用不把聊天落盘，刷新即清空；模型服务商的数据处理规则以平台为准。
- 选择照片后先在本地粒子化，同时重新编码为最长边 768 像素、最多约 240 KB 的 JPEG 缩略图。主动发送时才上传缩略图，每轮仅发送当前照片；可不写字直接点发送照片。更换照片会取消旧请求、开启新对话并恢复中性作品参数。
- 完整回复中的疏散、流动和冷暖参数经两端校验后平滑应用；无效参数、停止或请求失败保留已有画面。参数描述作品，不是心理评分。
- 关闭面板、返回暗房、清空对话或点停止都会取消正在进行的请求。取消不能撤回服务商已经接收的输入，也不保证已经生成的内容不计费。

## 实时语音

1. 已配置上述北京密钥时不用重新填一份。可选环境变量 `QWEN_REALTIME_MODEL=qwen3.8-omni-flash-realtime`、`QWEN_REALTIME_VOICE=Tina`，省略即使用这些默认值。文字型号不能直接代替 Realtime 型号；改动后重启项目。
2. 本机打开开发服务，点击「倾听 → 开始说话」，允许麦克风，等「在听」后说话。说完停顿约 0.7 秒由服务判断轮次，随后自动回应；不是承诺 0.7 秒内收到完整回复。
3. 回复时可直接开口插话，也可点「打断回复」，旧播放队列会清空。点击「结束语音」/关闭、切换入口、返回暗房、离开或隐藏页面都停止本次收音。单次最多 5 分钟，最多 2 个连接；重新开始建立新语境。
4. 看到麦克风权限提示时自行允许；若拒绝，可从地址栏站点权限恢复后再点开始。外放串音时可用耳机再试。真实设备的回声消除、音量和延迟需本人验收。

语音在开始后持续上传给百炼，程序不落盘录音或文字记录；当前对话历史独立，不能看到页面照片或文字聊天。每句稳定转写另交给现有 qwen3.8-flash 做作品转译（每句额外一次文本调用），与文字共用八项形态参数，最近 5 句/最多约 8000 字。插话同时取消待完成显影，结束/凝结/切换后迟到结果不改画面；失败可单独重试显影。打断不能保证已生成语音免计费；当前未采用未文档化的会话音频截断事件，模型可能保留没听完的语境。

浏览器仅连接同源 `/api/voice`，服务端附密钥连接百炼；网页不读取密钥。物理麦克风要求本机安全上下文或 HTTPS。`preview` 和纯静态托管无法提供这条后端链路。

## 需要排查时

| 页面表现 | 下一步 |
| --- | --- |
| 尚未连接 | 检查 `.env` 中密钥是否填写，停止旧任务并重新启动 |
| 服务尚未启动 | 用本项目 `npm.cmd run dev` 启动前后端；不要只启动 Vite、Live Server 或静态预览 |
| 密钥未通过验证 | 核对密钥有效性、北京地域及业务空间，然后重启 |
| 权限或额度不可用 | 查看模型授权、免费额度用完即停和账户状态 |
| 等待超时、连接中断 | 保留原文字，稍后重试；不要据此断言模型已成功接通 |

## 网站与后续分工

网站源码现在就在本地开发，暂时无需购买域名或服务器。此轮开发服务只监听本机，不能直接给同学远程访问。`npm.cmd run build` 验证前端产物，`npm.cmd run preview` 仅预览静态页面，不包含 AI 接口。

后续按以下顺序推进，每步检查可运行结果：

1. 已接通文字 API；继续本人体验，核对费用用量与更多网络条件。
2. 已接通照片理解和有限视觉参数；视觉效果与回应风格后续精修。
3. 实时语音已接通，合成音频识别/回复、浏览器采集处理与播放已验证；继续本人实测物理麦克风、扬声器、插话手感及费用账单。
4. 凝结、保存/散去和 IndexedDB 本地回廊已接通；照片与真实 AI 参数作品均完成刷新后恢复，不保存原始聊天或录音。本人操作见 README「凝结与本地回廊」。
5. 全流程稳定性与手机体验；再选择国内普通网络可访问的托管、配置 HTTPS 和线上后端。部署前移除外部资源访问障碍、加入适合公开试用的访问与额度控制，实际用手机流量、校园网验收。

真实呼吸识别、音乐、账户和跨设备同步仍属后续范围。国内 AI、北京接入点、国内网站可达是不同条件；最终“不需要 VPN”以整个网页和模型链路的现场测试为准。
