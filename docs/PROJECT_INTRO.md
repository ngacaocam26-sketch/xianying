# 显影 XIAN YING · 作品说明

> 一次轻轻的触碰，让无形，慢慢显影。

- **在线体验**：<https://xianying.art>（服务器在香港，晚高峰第一次打开可能需要半分钟；建议用手机自带浏览器或电脑 Chrome / Edge 打开）
- **代码仓库**：<https://github.com/ngacaocam26-sketch/xianying>
- **演示视频**：<https://www.bilibili.com/video/BV13cxv6DEAN>（2 分 29 秒）
- **开发者**：黄新意（独立开发）

## 一、一句话介绍

显影是一间「情绪暗房」：你用文字、声音或一张照片说出此刻的感受，AI 读懂处境后，为这一刻挑一个意象、起一个名字，把它显影成一件可以触碰、可以留下、也可以让它散去的粒子雕塑。

## 二、为什么做它

很多感受说不清，也放不下：委屈、焦虑、空落，常常只剩一句「我也不知道怎么了」。现有的情绪类产品大多是打卡、评分或问卷，把感受变成一个分数；聊天机器人则容易一味安慰，或者用术语给人贴标签。

显影想换一种方式：**不评判、不打分，让感受先被看见**。把模糊的情绪变成一个看得见、摸得到的形状，人就有了一个可以对着说话、可以拨开、也可以放下的对象。

## 三、体验流程

```text
表达 ──→ 显影 ──→ 触碰 ──→ 凝结 ──→ 留在回廊 / 让它散去
文字      雾散开     拨开它      定格       记忆碎片
语音      再凝聚成   AI 会感知    AI 起名
照片      一个意象   并轻声回应
```

1. **表达**：打开页面，暗房里只有一团慢慢飘动的雾。写一句话、点麦克风直接说，或者投一张照片。
2. **显影**：AI 的回复浮现的同时，雾先散开、停顿，再凝聚成这一刻的形状，旁边浮现它为这一刻起的名字，比如「压不住的火」「迟来的雨」。
3. **触碰**：
   - 手指按在雕塑上划动，会推开一个透着微光的小洞，像拨开一层雾。
   - 拨弄一会儿，AI 会感觉到，轻轻问你还有什么想说的，雕塑也随之松开、变亮。
   - 在空白处拖动，可以把它整圈转过来看。
4. **凝结**：想留下这一刻时点「凝结此刻」，画面定格，AI 为这一刻起标题、写一句总结。
5. **回廊或散去**：留下的作品以「记忆碎片」的样子存在回廊里：每件一块边缘被侵蚀、亮处漏出光尘的碎片，形状独一无二。也可以选择「让它散去」，粒子飘散，回到最初的那团雾。

## 四、作品亮点

### 1. AI 真正参与创作，而不只是一个聊天框

一句话会同时决定四件事：给你的回复、从 12 种意象里选哪一种、这一刻叫什么名字，以及 8 项连续的画面参数（疏散、流动、冷暖、开合、松紧、连贯、轻重、明暗）。

| 意象 | 动态 | 意象 | 动态 |
| --- | --- | --- | --- |
| 凝聚 | 几团软块挤在一起 | 雨 | 云下不停落雨丝 |
| 缠结 | 两股粗管互相缠绕 | 海浪 | 起伏的浪面 |
| 垂落 | 薄片层层下垂 | 漩涡 | 越往下转得越快的漏斗 |
| 舒展 | 宽带扭转着打开 | 云雾 | 柔软的雾团慢慢飘 |
| 离散 | 小块彼此隔开 | 尖刺 | 核心向外长出尖刺 |
| 火焰 | 火苗上窜、飞出火星 | 花开 | 花瓣从中心张开、呼吸 |

选择不是查关键词：提示词要求模型按真实处境来选。同样说「生气」，憋着的委屈可能是雨或尖刺，爆发出来才是火。同一种意象每次的角度、比例、节奏也略有不同。

### 2. 有分寸的回应：倾诉时陪着，提问时说透

- 用户倾诉时，回复两三句，抓住一个具体细节，把感受说得更准一点，必要时点出话里的矛盾，最多问一个具体的问题。
- 用户真的在问「为什么」「怎么办」时，把话说透：讲清常见的心理机制，标明哪些是推测，给一两个现在就能做的步骤。
- 对话可以一步步深入：用户开始怪自己时，会问一次这种感受以前在哪里出现过；用户自己说出过去的经历后，才用「我的一个猜想是」把现在和过去连起来。
- 明确的边界：不自称咨询师，不做诊断、不贴标签，不编造「研究表明」；用户表达自伤或伤人风险时，暂停艺术化表达，直接关心安全，并建议联系身边的人和当地紧急服务。

### 3. 触碰被感知：拨开它，它会回应你

这个功能来自试用者的建议。手指在作品上拨弄约 2.5 秒后，程序会把「用户没有说话，只是用手拨开了它」这件事告诉 AI。AI 回应的是这个动作本身，并轻声问一句还有什么想说的。回应和画面变化都由模型给出，不是写死的话术；对话里也会如实显示这是一个动作，而不是用户说的话。

### 4. 显影时刻与记忆碎片

- **显影时刻**：每次 AI 回应，粒子都会先散成雾、停顿，再凝聚成新的形状，对应「显影」这个名字。
- **记忆回廊**：回廊里的作品是实时渲染的粒子碎片。大形接近照片，边缘被侵蚀成残缺和散落的小块，亮处漏出带着画面颜色的光尘；轮廓由作品编号决定，每件都不一样。

## 五、技术实现

```text
浏览器（React + TypeScript + Three.js）
  ├─ 粒子雕塑与照片浮雕：自写 GLSL 着色器，十几万颗粒子，屏幕空间推开小洞
  ├─ 回廊记忆碎片：独立 WebGL 画布，谐波轮廓 + 值噪声侵蚀
  └─ 本地回廊：IndexedDB，作品只存在用户自己的浏览器里
        │ HTTPS / WebSocket
Node 服务（同一端口提供页面、/api 与语音）
  ├─ /api/chat       流式返回回复 + 作品参数 + 意象（JSON Schema 约束）
  ├─ /api/sculpture  语音内容转译为作品参数
  ├─ /api/title      凝结时起标题和一句总结
  └─ /api/voice      实时语音中转
        │
阿里云百炼（北京）
  ├─ qwen3.8-flash               文字对话、看照片、起名
  └─ qwen3.8-omni-flash-realtime 实时语音对话
```

- **前端**：React 19、TypeScript、Vite 8、Three.js。
  - 粒子的形态、动态、显影过程和推开小洞都在着色器里完成，12 种意象各有自己的动态。
  - 手机上会自动降低粒子密度，并在回复出现时给卡片让出位置。
- **AI 输出是受限的数据，不是代码**：模型按 JSON Schema 返回结构化结果，意象只能从固定枚举里选；服务端和前端再各校验一次，不合格就保留当前画面。
- **安全**：密钥只放在服务器的环境变量里，浏览器拿不到；接口会校验请求来源，并设了全站并发和频率上限，防止额度被刷。
- **兼容**：构建目标降到 ES2019，兼容较旧的 App 内置浏览器；页面在脚本加载前先显示提示，加载失败时提示改用系统浏览器。
- **部署**：香港轻量应用服务器（免备案）、Caddy 自动 HTTPS、systemd 常驻。

## 六、隐私与伦理

- **数据去向**：
  - 发送的文字、最近几轮对话，以及主动发送的照片缩略图（最长边 768 像素），会交给阿里云百炼处理。
  - 语音只用于实时对话和转译，不保存录音。
- **作品只存在本地**：回廊保存在用户自己的浏览器里，不上传、不跨设备同步，清除浏览器数据就会消失。
- **不是心理测评**：画面参数是 AI 对这一刻的艺术转译，不是心理评分；作品旁边浮现的名字描述的是作品，不是对用户的判断。
- **开发与测试只用虚构数据**：提示词调优、截图和自动测试都使用虚构的句子和自绘的测试图片。

## 七、测试与验证

- **自动测试 53 项**，覆盖：
  - 12 种意象的几何数据、显影节奏；
  - 作品存档与旧版本兼容；
  - 接口格式与输入校验、限流配置；
  - 语音中转、记忆碎片轮廓。
- **回复风格的 A/B 对比**：用多段虚构对话（包括多轮）在真实模型上对比提示词的各个版本，前后迭代 7 版。
- **浏览器验证**：在无头浏览器里模拟手机和电脑尺寸，截图检查显影、回廊、照片比例、返回手势、拖动手势和启动提示。
- **真实试用**：几位试用者的反馈直接带来了多项改进：
  - 开场改成一团雾；
  - 粒子更细；
  - 回廊改成碎片；
  - 提问时把话说透；
  - 照片处理完成前不能发送；
  - 拨开时 AI 会感知；
  - 雕塑可以整圈旋转。

## 八、如何运行

**在线**：打开 <https://xianying.art>。

**本地**（需要 Node.js 24 和阿里云百炼 API Key）：

```powershell
git clone https://github.com/ngacaocam26-sketch/xianying.git
cd xianying
npm ci
# 新建 .env，写入：DASHSCOPE_API_KEY=你的密钥
npm run dev
```

浏览器打开终端里显示的地址即可。没有密钥时，粒子和照片浮雕仍可使用，AI 对话不可用。部署方法见 [DEPLOY](DEPLOY.md)。

## 九、已知限制与后续计划

- **网络**：服务器在香港且线路未针对内地优化，晚高峰首次加载偏慢。后续可把静态资源放到内地存储或换优化线路。
- **模型**：使用的是轻量模型，偶尔仍会出现提示词禁止的说法，比如在用户没提过去时猜测早年经历，但会标明是猜想。
- **回廊只在单个浏览器里**：这是有意的私密设计，但也意味着换设备就看不到。后续可以加导出功能。
- **后续想做**：
  - 环境音与声音反馈；
  - 更有仪式感的「长按散去」；
  - 让更多对称的意象自动整圈旋转。
